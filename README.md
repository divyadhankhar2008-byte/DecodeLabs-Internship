# 💰 Expense Tracker

**DecodeLabs Project 2**  
**Author:** Divya Bharti  
**Batch:** 2026

## Description

A simple command-line expense tracker built with Python. This program allows users to track their daily expenses by entering amounts one by one and displays a running total.

## Features

- ✅ Add expenses interactively
- ✅ Real-time running total display
- ✅ Input validation (handles invalid entries)
- ✅ Clean, formatted output
- ✅ Simple quit command to exit

## How to Use

1. Run the program:
   ```bash
   python expense_tracker.py
   ```

2. Enter expense amounts when prompted:
   ```
   Enter expense amount: 50
   ✅ Added! Running total: $50.00
   ```

3. Type `quit` to see your final total and exit:
   ```
   Enter expense amount: quit
   
   ========================================
      FINAL TOTAL: $150.00
   ========================================
   ```
