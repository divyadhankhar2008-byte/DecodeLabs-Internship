# 🚀 DecodeLabs Internship Projects

A comprehensive collection of Python projects completed during the DecodeLabs Industrial Training Program. This repository showcases fundamental programming concepts including data structures, input validation, defensive coding, and interactive CLI applications.

## 📋 Projects Overview

### 1. 📝 To-Do List Application
**File:** `todo.py` | **Documentation:** `todo-README.md`

A feature-rich command-line to-do list manager with persistent task management.

#### Features:
- ✅ Add, view, and delete tasks
- 📊 Interactive menu-driven interface
- 🔢 Task numbering with `enumerate()`
- 🛡️ Input validation and error handling
- 💾 Data persistence
- 📱 User-friendly CLI experience

#### Key Concepts:
- Lists and list manipulation
- Functions and modular design
- Loops and control flow
- `enumerate()` for indexed iteration
- File I/O operations

#### Usage:
```bash
python todo.py
```

Follow the interactive menu to manage your tasks.

---

### 2. 💰 Expense Tracker
**File:** `expense_tracker-1.py` | **Documentation:** `expense-README.md`

A comprehensive expense tracking system for personal budget management.

#### Features:
- 💸 Add, track, and categorize expenses
- 📈 View spending summary and analytics
- 🏷️ Category-based organization
- 🔍 Filter expenses by category or date range
- 📊 Generate expense reports
- 🛡️ Input validation for financial data

#### Key Concepts:
- Accumulator pattern for aggregating data
- Dictionary operations for categorization
- Data validation and defensive coding
- Complex data structure management
- Financial calculations and reporting

#### Usage:
```bash
python expense_tracker-1.py
```

Use the menu to add expenses, view summaries, and generate reports.

---

### 3. 🔐 Password Generator
**File:** `password_generator.py` | **Documentation:** `password-README.md`

An enterprise-grade random password generator with advanced security features.

#### Features:
- 🎲 Random password generation with customizable length
- 🔤 Multiple character sets (uppercase, lowercase, digits, special characters)
- ⚙️ Configurable complexity levels
- 🛡️ NIST 2024 compliance
- 📋 Batch password generation
- 🔍 Password strength validation
- 🎯 Preset configurations for common use cases

#### Key Concepts:
- String manipulation and character handling
- Random module for cryptographic operations
- Regular expressions for validation
- Algorithm design for security
- Configuration management

#### Usage:
```bash
python password_generator.py
```

Generate secure passwords with your preferred settings.

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
- Terminal/Command Prompt access
- Basic understanding of CLI operations

### Installation

1. Clone the repository:
```bash
git clone https://github.com/divyadhankhar2008-byte/DecodeLabs-Internship.git
cd DecodeLabs-Internship
```

2. Verify Python installation:
```bash
python --version
```

3. Run any project:
```bash
python <project_name>.py
```
